# Agent Deployment Skill

Deploy AI agents to Microsoft Foundry via GitHub Copilot.

## Installation

Copy this folder to your skills directory:

```bash
# For GitHub Copilot
~/.copilot/skills/agent-deployment_ai_toolkit

# For Claude
~/.claude/skills/agent-deployment_ai_toolkit
```

## Usage

Ask Copilot: "Deploy my agent to Foundry"
